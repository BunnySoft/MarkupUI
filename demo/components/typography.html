    Behavior and accessibility

    Typography, Text, Paragraph, Heading, Link, Blockquote, UnorderedList and OrderedList extend the shared ViewElement. Their canonical tags are m-typography, m-text, m-p, m-heading, m-link, m-blockquote, m-ul and m-ol. Text is an inline presentation frame; Typography is a rich-document styling scope. Neither invents semantic roles.

    Paragraph, Heading, Link, Blockquote and the lists adopt a single authored native owner, or generate one around the original content. Put real li children inside lists and nest further lists inside an li. Author phrasing content in paragraphs/headings and do not nest links. Native strong, em, del, inline code and pre/code remain native content; this family does not replace the separate List or Code families. Existing scoped native CSS remains usable.

    Heading level is an integer from 1 to 6, default 2. A matching authored heading is adopted. Changing level replaces the native h1–h6 shell, copying its attributes and moving its original children. Descendant identity, listeners, focus and selection survive that change; listeners attached to the replaced shell do not. Bind stable behavior to the host or surviving content, and read native again after level changes. Other scalar updates do not replace native owners.

    Text and Paragraph type is default, success, info, warning or error; depth is 1, 2, 3 or null. Text's strong, italic and underline flags are presentation only. Heading prefix is bar or null; alignText hangs the decorative bar, list markers or quote border outside the text baseline. Exact colors, sizes, margins, code radii and fonts remain the existing CSS theme resources.

    Link exposes nullable href, target, rel, download and hreflang, retaining adopted native values when no host override exists. Blockquote exposes nullable cite. OrderedList start is null or a signed 32-bit integer, type is null or 1/a/A/i/I and reversed is boolean. Null removes an override; implicit reversed numbering and li[value] are browser-owned. Native names and ARIA belong on the native owner, not a redundant host role. Link.focus()/blur() delegate to its anchor; activation stays native—use the actual anchor, including native.click() for programmatic activation.

    Invalid property writes throw before mutation; invalid raw attributes are rejected rather than silently defaulted. Pre-upgrade assignments are replayed. Direct child additions are adopted on the next mutation microtask. Disconnect releases observers; reconnect keeps surviving nodes, native values and listeners without duplicate shells. Removing a focused subtree itself follows native browser focus behavior; reconnect does not steal focus back. Author native owners for semantic fallback before JavaScript loads. The runtime loads no API JSON or optional query engine.
