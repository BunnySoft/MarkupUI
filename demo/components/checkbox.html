Behavior, dependencies and styling

Checkbox defaults follow the native input: unchecked, not indeterminate, not disabled or required; value is "on" and name is empty when absent. Group min is 0, max is null (unlimited), size is medium and status is null. Group values include prechecked and disabled members; writes outside limits are allowed without clamping so applications can restore or repair state.

The checked host attribute sets the native reset default. Use checked for silent live writes and defaultChecked for reset defaults. Native value/name/form changes remain live. The string value is for submission: existing m-bind on Checkbox still binds boolean checked; an explicit m-bind-property="value" binds the submission string. Canonical Radio follows the same native binding rule; Switch retains its existing bridge.

Typed writes validate before changing native state. Within a group, Checkbox value rejects empty or duplicate keys; direct native value changes can instead make a group invalid and are reported on refresh. CheckboxGroup value accepts unique existing strings in any order but reads back in DOM order. Append members inside an authored native fieldset, or directly to a group whose fieldset was generated.

Native input then change bubble from the native checkbox once per accepted activation. The group emits one non-bubbling m:checkbox-group-change afterward with values, value and actionType. Cancelled clicks emit neither; invalid group members report non-bubbling m:checkbox-group-error with message, and refresh throws. Removing a group cancels queued notifications and releases only owned ARIA; reconnect preserves authored nodes and listeners.

ESM imports only markup-ui-core.js. Classic scripts require markup-ui-core.global.js then markup-ui-checkbox.global.js, exposing Checkbox, CheckboxGroup and registerCheckbox on MarkupUICheckbox. No native-input dependency, aggregate, binding engine, renderer helper or other component is required. CSS is markup-ui-checkbox.css. The manifest counts the complete two-file runtime plus CSS.

Use native labels and a nonempty first direct legend. Omitted input/fieldset chrome is generated once around surviving authored nodes. Native controls, not hosts, own roles and focus. Interactive Checkbox remains forbidden in passive Collapse, Tooltip and Dropdown labels. The .m-checkbox/.m-checkbox-group skins remain native styling hooks; --m-checkbox-* and shared theme tokens customize color, font, size and focus without changing ownership. Native appearance, RTL, wrapping, forced colors and print are retained; there is no animation requiring a reduced-motion substitute.
