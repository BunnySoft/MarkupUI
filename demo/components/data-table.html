Data, Forms and Ownership

Public examples author only m-* elements. The Web renderer creates the captioned table, headers, filters, page controls, summary text and scoped native checkboxes. The composed Data Table stylesheet includes Table styling; no Table registration or native template is required.

options defines labelled columns, optional text/number sorting, literal filtering, page sizes, selection name/scope and summaries. Custom comparators, predicates and summaries receive immutable data records and must return synchronous finite numbers, booleans and text respectively. They never need an HTML row. JSON attributes support data and callback-free configuration.

data supports at most 2,000 unique keyed rows and 64 columns, including the selection column. Sort ties preserve source order. Filtering precedes sorting and paging. Changing data keeps surviving native rows and unchanged cells, including their edits, listeners and focus. A rejected callback leaves committed data and DOM unchanged.

Row checked flags establish native reset defaults; checkedKeys represents current selection. Disabled choices are protected. Filtering and paging hide rows without disabling their fields, so hidden selected checkboxes remain successful form controls. Use reveal or revealAll before focusing invalid fields. Loading reports aria-busy without disabling form controls.

Disconnect before replacing schema. Reconnect retains live state and the original reset configuration. Native is a Web inspection surface, not a second row data source: update data rather than insert native rows. Form, Button, Box and Typography are additional demo selections, not Data Table dependencies.
