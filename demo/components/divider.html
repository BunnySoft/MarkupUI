Semantics, content and lifecycle

One rule owner, independent title content

Semantic Divider exposes one native hr as the separator owner. The host and generated title container do not receive separator roles or aria-hidden. A trailing painted line is decorative. An authored h1–h6 remains a real, independently accessible heading; plain text is not promoted to a heading.

semantic = false hides only the rule from accessibility APIs, never the title. The optional label names only that rule. It is not copied from title text and does not replace, label or hide the title. Null removes the rule label; an empty string is an explicit empty label.

Author one noninteractive text/heading fragment as primary content. Do not put captions inside hr, and do not add separator roles or aria-hidden to the host. Use semantic and label instead. Divider creates no button, tabindex, keyboard handler, synthetic heading role or live region. Native links and controls around it keep their normal focus order.

Orientation and placement

Orientation changes the native rule's aria-orientation and geometry. Horizontal titles use start/center/end logical placement, respecting surrounding text direction. Vertical titles remain beside the rule; start/end align them toward the start/end of its block extent, while center is the default. Title placement does not shorten a plain untitled divider.

Dashed is a presence boolean: set the property false or remove the attribute to disable it. Semantic is a boolean-text attribute with an absent default of true; use semantic="false" for decorative rules. Enum setters reject unsupported values such as left/right or diagonal.

Identity and cleanup

Divider moves, rather than clones, primary nodes into a private title container. Existing headings, text nodes and listeners survive property changes. Late children and text edits are observed. Direct templates, scripts and styles are left in place rather than treated as title content.

Disconnect stops observation. Reconnect reuses the same private rule and surviving title nodes, applying properties changed while detached. Replaced or removed authored content is not resurrected. Authored hidden attributes remain the author's responsibility; Divider never hides a meaningful title automatically.

Styling and delivery cost

Defaults retain light rule/text colors #efeff5/#1f2225 and dark white/.09 and white/.9. Captions are 16px/500, block spacing is 24px, inline spacing is 8px and title gap is 12px. Heading semantics are independent from this caption typography; inline author styles remain intact.

Override --m-divider-color, --m-divider-text-color, --m-divider-thickness, --m-divider-space, --m-divider-inline-space, --m-divider-label-gap, --m-divider-label-size, --m-divider-label-weight and --m-divider-length as needed. Scope any private part styling to the owning m-divider; parts are not authoring elements.

Rules use printable borders, not background images. Forced colors use CanvasText and no motion is added. New JavaScript ceilings are 3,000 gzip bytes per format and 5,000 including core; the existing 1,500-byte CSS ceiling is unchanged. Count core plus component plus CSS for the first load.
