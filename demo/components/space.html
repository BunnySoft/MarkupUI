Behavior and accessibility

Space extends the shared ViewElement. Defaults are row direction (vertical=false), block flex (inline=false), wrap=true, size=medium, align=normal and justify=start. Start/end map to flex-start/flex-end; normal retains native flex alignment rather than inventing a centered default. A vertical Space always uses nowrap; its stored wrap preference takes effect when returning to a row. Distributed justification may add space beyond the gap.

rowGap and columnGap are null or finite nonnegative numbers, mapped to CSS pixels on Web. Null selects the preset/style resource. Fractions and zero are valid; axes do not swap in a column. Presence attributes vertical and inline are enabled even when their text is "false"; remove them to disable. wrap accepts empty/true/false, with absence meaning true. Invalid properties throw before mutation; invalid attributes throw on validation/read, not silently default.

No item count, separator, wrapper, style-object or gap-detection API is provided. Text, comments, templates, hidden and empty children follow native layout rules; author real groups where stable boundaries matter. No child is moved, cloned or replaced. Late children need no refresh. No observer, event handler, role, tab stop or semantic control is created. Native links, buttons, labels, focus and form behavior stay native.

Passive Space content is allowed in Collapse headers, Dropdown labels and Tooltip panels, but each consumer still rejects interactive descendants and arbitrary widgets. Space itself permits ordinary interactive content outside those restricted regions. Do not put Space between a list and its li children.

Colors, decoration, percentages, writing modes and responsive styles belong to Web CSS/theme resources. --m-space-row-gap, --m-space-column-gap, --m-space-align and --m-space-justify override preset CSS; explicit typed gaps temporarily own native row-gap/column-gap, without inheriting into nested Space. The optional Web-only m-space-item class gives an authored direct item border-box/max-inline-size safety; it is not an element or a portable property. Other direct children retain min-inline-size:0.

Pre-upgrade properties replay before rendering. Disconnect restores only owned gaps, preserving later application edits; reconnect reapplies typed values without extra content. Native CSS layout remains available without JavaScript, but numeric attribute gaps and typed property updates require the runtime.

Outside Space, native content and styles remain unchanged.
