Watermark: one decorative native tile

This local example is labelled LOCAL DRAFT in ordinary readable text. The repeated pixels are decoration, not security, access control or screenshot prevention.

Original native document and controls

Select this original text through the decorative overlay. Links, controls, selection, copy and form validation remain native.

A positioned outer wrapper covers the visible inner scrollport. Repetition is a CSS background, not one DOM element per stamp.

If the positioned wrapper itself scrolls, its absolute overlay moves with the initial box and does not cover the full scrollHeight. This is a real limitation, not an anti-tamper mechanism.

Viewport-fixed mode requires a direct-body root without transformed, filtered or contained root/body/html ancestors. Native dialogs/popovers can appear above it.

No font download, image transport, canvas package or remote watermark service is installed.

Pixel colors do not automatically become theme tokens. Important classifications belong in ordinary text too. Print and forced-colors omit decoration.

There are no hidden form fields, selection blockers, global storage or security promises.

Native link to the footer 
No JavaScript: original document, text, image, form fields and links remain; the decorative overlay is hidden.

Resizing repeats the same tile without re-rendering the document. Automatic DPR updates are event-driven and bounded; late image/PNG results cannot replace a newer tile.
