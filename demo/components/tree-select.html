Behavior and Ownership

Author only m-* elements. The Web renderer owns the native select, filter and clear button; no hidden native tree, active Tree or Select element is required. Options are immutable data snapshots with at most 2,000 unique keys and 64 levels. Groups are not selectable. Lazy loaders and cascading checkboxes are not part of this component.

Single values are a string or null; multiple values are independent dense arrays. Sparse or invalid value/default arrays fail before writes. Programmatic writes are silent. Native selection and successful clear actions emit m:tree-select-change from the host. defaultValue remains independent from value; reset skips unavailable defaults without choosing unrelated items.

Disconnect before changing multiple, filterable or settings. Reconnect preserves the native control and option identity. Live options updates retain surviving keys and focus, prune unavailable selections and preserve missing reset targets. The native property is an explicit Web inspection surface, not portable authoring.

Form, Button and Typography are additional selections used by these examples, not Tree Select dependencies. Applications provide their own labels and form names.
