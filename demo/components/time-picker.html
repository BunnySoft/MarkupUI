Value, events and lifecycle

  • value is the live native string. Empty is "", never null; midnight "00:00" is not empty. Invalid nonempty strings, dates, offsets, numbers and null throw before changing data. Grammar is HH:mm, optionally :ss and 1–3 fractional digits. Unsupported native fractional precision fails explicitly, rather than silently changing its meaning.
  • The markup value attribute and typed defaultValue configure the native reset default. The value property is a silent live write and does not rewrite that attribute. Updating a default follows native dirty-value rules; native form reset is silent and cancellable.
  • clear() returns false for empty, readonly or unavailable fields. A successful clear retains defaults, emits one native input/change pair and one m:time-picker-clear. Native events still bubble; m:change reports a changed live value once, not again for the subsequent unchanged change event. Use value = "" for a silent programmatic empty value.
  • format remains an optional hint, not a Web token-formatting engine; it has never controlled native display. Browsers choose localized UI. Even format="HH:mm" does not remove seconds or milliseconds from data. Native min/max (including overnight bounds), step, required, readonly and custom validity stay native.
  • native is null before rendering, then exposes the stable native field for explicit Web name/form/constraint integration. A generated field has the default accessible name “Time”; host aria-label overrides it. Authored fields need their own label or aria-label. Unsupported anatomy and automatic failures report m:error with the error; a failed enhancement is not treated as success.
  • Disconnect cancels queued actions and releases enhancement resources without resetting live/default values. Reconnect reuses the same field, labels, authored nodes and clear button. Programmatic live/default updates while disconnected are retained.
