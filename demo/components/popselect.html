Without JavaScript, all choices below their labels remain inline and usable. Native reset works.

Closed popover fields still serialize and validate. The submit demo first runs quiet native Form validation, explicitly reveals only the first invalid field's owner/ancestors, then focuses and reports that one control. It never silently disables a hidden required field or treats dismissal as Cancel.

Popup geometry reuses the existing Popover contract. CSS zoom on its ancestor context is rejected with a readable inline handoff; native browser/visual-viewport zoom remains separate. No second positioning engine is added to compensate for unsupported CSS zoom.
