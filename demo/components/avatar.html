Behavior and accessibility

Resources and events

A new source starts loading; an unchanged source does not retry. Clear or change it to restart. Primary failure attempts one distinct fallback URL. Changing fallback alone does not restart a settled request. Removing a host source clears it.

m:load carries { src } after success. m:error carries { src, fallback, state } per failed attempt; the primary failure may report loading while the fallback starts. Property assignment does not fabricate input/change events.

Content and names

Use m-avatar-placeholder while loading and m-avatar-fallback after failure. Each region accepts static content or one template instantiated once per region lifetime. Update rendered content or replace the region; template edits are not reactive. Interactive descendants and duplicate regions/source images are invalid.

Explicit host ARIA takes precedence. An empty label makes the avatar decorative; null releases the override. Otherwise authored image alt or ordinary text supplies the name. Generated images have empty alt text so the host owns the name.

Sizing and groups

Named sizes are 22/28/34/40/46 CSS pixels; numeric sizes must be finite and positive. Borders add four pixels to outer dimensions. Text is fitted without changing its full accessible label. Colors, radius, font and border paint use --m-avatar-* tokens.

AvatarGroup preserves member identity and uses native details/summary for keyboard-accessible overflow. max = null is unlimited and zero puts every member in overflow. Negative, fractional and nonfinite counts are rejected. Collection binding and arbitrary item/rest template APIs are not included.

data-part and data-state are renderer-owned markers, not an alternative authoring API.
