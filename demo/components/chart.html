  import * as echarts from "./vendor/echarts.js";

Supply your own ECharts module at the vendor path. ESM imports only core and the small adapter from MarkupUI. This demo builds selected ECharts 6.1.0 modules separately under demo/vendor, with their licenses; they are not published in the package. 
// npm application (bundler)
import * as echarts from "echarts";
import { configureChartEngine } from "@dataengine/markup-ui/chart";
configureChartEngine(echarts);
For a tree-shaken engine, register BarChart, LineChart, PieChart, ScatterChart, AriaComponent, DatasetComponent, GridComponent, LegendComponent, TitleComponent, TooltipComponent, SVGRenderer and CanvasRenderer using echarts.use before configuration. The classic vendor path must supply a classic ECharts script. No global discovery or CDN fallback occurs. Missing setup produces state="error" and m:chart-error on render; after late setup, call refresh() on affected charts. Configuration affects future instances, not existing ones. Trusted direct options
Direct option mode is Web-specific and exclusive with configuration children. Supply tableSource as the readable alternative. It supports the same first-batch series; adding engine modules does not expand the supported option contract.
Data, updates and accessibility One source per dataset: property or scoped binding, JSON attribute, nested JSON, or remote src. Dispose any binding and call clearSource() before switching source kinds. Assign new data or call refresh() after an in-place edit. Null cells are missing values; non-finite numbers, functions, accessors, hidden symbols, custom array prototypes and unsafe keys are rejected. Dimensions use dense arrays of safe, unique names; absent record cells never read inherited values. Remote data is limited to same-origin HTTP(S), JSON content types and 1 MiB. Credentials and redirects are disabled. Requests time out after 15 seconds and are cancelled on source changes and disconnect. reload() reports failure through its rejected promise and the dataset error event. Previous data remains available during reload; a chart configuration or loading error clears the rendered chart. Each dataset is limited to 10,000 rows and 64 columns; each chart to 16 datasets and 32 series. Data tables use 50-row pages. SVG is the default Web renderer; renderer="canvas" is available. Theme is light or dark. Every chart requires aria-label or aria-labelledby. The built-in data disclosure is keyboard-accessible native markup. Chromium, Firefox and WebKit desktop/mobile-sized checks pass; real-device and screen-reader acceptance is still pending. Declarative tooltips use ECharts rich-text rendering, not HTML. Direct option callbacks and HTML configuration are trusted application code. Updates replace the full option, so removed collections cannot survive through implicit merging. Disposed or replaced renderer callbacks cannot emit current selections. Core and unrelated components do not import ECharts.
