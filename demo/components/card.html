API

Generated from TypeScript accessors and documentation comments at build time, separately from the runtime. Native HTMLElement properties and methods remain available.

Behavior and accessibility

Properties and validation

size accepts small, medium, large or huge. Invalid choice or boolean-text attribute values throw on property read; invalid property assignments throw before changing the attribute. Remove an attribute to restore its default. bordered and closeFocusable accept empty/true/false text, defaulting to true.

closable, hoverable, embedded, segmented and contentScrollable are presence booleans: even the text "false" is present. Assign false or remove the attribute to disable. title is plain text and only supplies a generated header when there is no authored header. closeLabel trims whitespace and falls back to “Close card” when absent or empty.

Region ownership

Author at most one of each region, in cover/header/content/footer/action order. Direct header-extra regions move into the selected header before Close. Existing nested header-extra content stays authored; nested Cards own their own regions. Authored region order is otherwise retained. Duplicate regions are neither merged nor discarded: the first direct header/content receives generated content; use one each.

Free-form nodes move, without cloning, into content. A late explicit header/content replaces its generated wrapper and keeps surviving authored nodes and listeners. An explicit header takes precedence over the text title. Templates, scripts and styles are not adopted as content. Reconnection retains authored state and only reinstalls Card's own listeners.

Finite segmentation

segmented enables top separators for content, footer and action. Each segmentedContent, segmentedFooter or segmentedAction override accepts null (inherit), "" or "true" (full width), "false" (off), or "soft" (inset). This is a finite attribute contract, not a policy object. CSS follows direct DOM region order and ignores regions with hidden: the first visible region has top spacing but no separator. Use hidden, not arbitrary display rules, to remove a region from separator ordering.

Close intent and semantics

A native button type="button" emits one bubbling, cancelable m:close event with detail.originalEvent. Card never hides or removes itself. Canceling marks the application's intent as vetoed; there is no built-in dismissal to undo. Application listeners should inspect defaultPrevented before dismissal and check event.target when nested Cards bubble events.

card.addEventListener("m:close", event => {
  if (event.target !== card || event.defaultPrevented) return
  // Application decides whether and when to dismiss.
})

Native Enter/Space activation, disabled fieldsets and focus behavior remain native. Card adds no landmark, heading level or host tab stop. Supply a meaningful heading, role/name and localized close label as appropriate. Hoverable is visual only.

Constrain Card height and set content-scrollable for independent content scrolling. Make authored scroll content keyboard-accessible with a suitable tabindex, role and name, as in the Task List example. Style public m-card-* regions and --m-card-* CSS variables; generated data-part/data-state markers are private and owner-scoped.
