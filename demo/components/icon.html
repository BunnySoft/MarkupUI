Behavior and accessibility

Icon and IconWrapper extend the shared ViewElement. Neither fetches assets, rewrites SVG paint, generates a role, adds a tab stop or emulates a button. SVG titles/descriptions, image alt text, authored ARIA and native action semantics remain unchanged. Hide decorative graphics with aria-hidden on their frame; name a meaningful SVG or image through its native accessible name.

Size accepts positive finite numbers or null. Null preserves style resources: Icon defaults to an inherited 1em box, and IconWrapper to 24px. Depth is null or an integer from 1 to 5; its Web attribute uses the exact values 1, 2, 3, 4 and 5. Invalid properties throw before changing attributes.

Color, wrapper background/radius, depth opacity and authored transforms are style resources. Web CSS customization is not a cross-platform class API. Do not use Icon as a replacement for a native button/link or place interactive controls inside an icon in a passive-content region.

Updates never clone or replace content. Pre-upgrade properties are replayed, and disconnect restores only owned sizing styles without erasing later application edits. Late native content requires no refresh. Depth and color transitions honor reduced motion and forced colors. Without JavaScript, authored content remains visible; typed property updates require the runtime.
