Migration and native form limits

Keep visual placement consistent with semantic DOM/tab order. Rewrite the meaningful source order rather than swapping controls with push, pull, grid rows or order. An offset is not an absolute grid start line.

Hidden named fields still submit and can validate; hiding is not disabling. This example keeps the hidden value non-required. Applications must reveal hidden invalid controls before validation, or explicitly choose another policy.

No legacy Row/Col constructors, responsive parser, generated item wrapper, layout timer or new distribution asset is provided. Existing legacy MarkupUI wrappers and modern Grid acceptance are unchanged.
