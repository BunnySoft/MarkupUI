Radio

Radio, RadioGroup and RadioButton are ViewElements. One native radio and label own activation, exclusivity, focus, validity and submission. RadioButton changes the presentation, never the control or keyboard engine.

Behavior, dependencies and styling

Radio and RadioButton default to native unchecked, disabled=false, required=false, value="on" and name="". Size is medium. The checked attribute sets defaultChecked, not controlled live checkedness. Use the native form attribute for an external association. Native label/input content is adopted without cloning; omitted chrome is generated once around surviving content. Hosts have neither roles nor tab stops.

RadioGroup requires a nonempty first direct legend and one complete light-DOM native group. Members need real labels, explicit nonempty unique string values, one common nonempty name and one actual form owner. Empty groups read value/name/form as null; null clears selection. Unknown, empty, duplicate or non-string keys are rejected. Unresolved form targets, mixed owners, same-name/form outside peers and mismatched nested groups are explicit errors. Disabled selected members are still selected but are not successful form controls.

Group value is computed from checked members, never cached. Its value attribute requests selection once when applied; property writes and reconnect do not reapply stale attributes. Removing the selected member does not choose a replacement. Refresh validates late/reordered/nested content and clears errors. Direct native peer changes retain browser exclusivity even when invalid scope makes group reads/writes throw; remove the conflict and refresh to read the actual remaining selection.

Native input then change bubble once from the selected radio. The old peer receives no synthetic change. The group emits one non-bubbling m:radio-group-change afterward with value; reset, cancelled activation and programmatic writes do not emit it. m:radio-group-error carries message; error retains automatic validation failures. Removing a group cancels queued notifications; reconnect preserves controls, defaults, listeners and authored content.

m-bind on Radio/RadioButton binds boolean checked; explicit m-bind-property="value" binds the native submission string. RadioGroup binds the computed string/null value through its group event; unmigrated Switch keeps its existing bridge. Prefer a group value binding when representing exclusive selection.

ESM imports markup-ui-core.js and markup-ui-native-radio.js. Classic loading is core, native-radio, then markup-ui-radio.global.js; MarkupUIRadio exposes Radio, RadioGroup, RadioButton and registerRadio. The private native-radio dependency is also used by unmigrated Rate and registers nothing. There is no public createRadioGroup helper, text-input engine, aggregate or another family's constructor in this graph.

Use canonical size and group status attributes, not the archived data-size/data-status configuration. Native .m-radio/.m-radio-button/.m-radio-group skins remain for authored controls. --m-radio-* and shared theme tokens customize color, font, dimensions and focus. Existing colors, four-pixel button seams, native pressed/focus/disabled painting, RTL and forced colors remain; no animation needs a reduced-motion replacement. Interactive radios are prohibited in passive Collapse, Tooltip and Dropdown labels.
