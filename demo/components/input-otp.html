Value, events and lifecycle

  • There is one native input, not a group of mirrored digit cells. Native paste, selection, keyboard navigation, autofill and IME are untouched; there is no paste distribution or focus-moving engine.
  • value reads the actual native draft. Setting it or calling clear() is silent and never truncates scripted values. The value attribute and defaultValue property set the reset default, respecting native dirty-value semantics.
  • Native input/change replace the old value-carrying m:change event. The sole completion event is m:input-otp-complete, bubbling from the native field with frozen { length, characters } metadata. It replaces m:complete; no alias or passcode payload remains. Read value explicitly if needed.
  • Completion waits until composition and the current event task settle, includes native/custom validity, and is deduplicated until the code becomes incomplete. Complete-to-complete replacements, programmatic writes, defaults, reset, refresh and schema changes do not emit completion. Disabled, readonly, hidden and inert fields do not notify.
  • length is an integer from 1 to 12 (default 6), counted in native UTF-16 code units. characters selects digits (default) or alphanumeric ASCII. Invalid drafts, Unicode and combining sequences stay intact. An authored native pattern or explicit pattern is a Web constraint override; null restores the ASCII preset. Invalid typed data and malformed pattern syntax fail explicitly.
  • Length/preset/pattern updates configure the same owner and preserve native value, default, selection and focus. Text/password masking is live. Other direct native structural changes invalidate and disconnect the owner; restore valid anatomy and call connect() explicitly. refresh() never silently creates another owner.
  • Removal cancels pending completion and releases listeners, observers and status/presentation leases. Reconnection adopts the same input and current defaults. Optional status is a Web-only original plain nonlive node, changed while disconnected. Native names/FormData, labels, authored ARIA and listeners remain native; the host is not another focusable field.
