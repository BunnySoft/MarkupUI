Single, empty and placeholder

A selected empty string is not null. The first marked empty option is a native placeholder; null means selectedIndex -1 and no submission.

Multiple list and literal filter

Use Ctrl/Command or Shift for native multiple selection. The optional external input filters literal option/group text, not remote search or virtualization. Selected nonmatches remain visible.

Defaults, forms and validity

There is no Select defaultValue. option.defaultSelected and selected attributes are reset defaults; live writes follow native dirty selectedness. Only native form owners submit.

Behavior, accessibility and delivery

Select extends the shared ViewElement and registers only m-select. Author one native select, or direct native option/optgroup nodes which are moved into a generated select. Give the native owner a label, aria-label or resolved aria-labelledby. Host naming/description/invalid ARIA and name, form, disabled, required, multiple, autocomplete attributes forward on adoption and later host changes. list-size maps to native size. Direct native accessors do not reflect back to the host. Do not add a host role/tabindex or put Select in passive headers, Tooltip content, Dropdown labels or interactive wrappers. Native readonly and a replacement m-option are not supported.

Every option requires an explicit unique native string value, including "". Direct options or one direct optgroup level with nonempty labels are supported. Duplicate/missing keys, unknown API values, wrong-mode values and repeated array keys throw. Single value is string or null; multiple value is a DOM-order string array, not an empty-array configuration default. Disabled choices can be selected programmatically. Native collections remain live; late insertion, removal and reorder follow native selectedness and never resurrect missing keys. value/selectedIndex writes are silent; use options and option.defaultSelected for defaults. No host value/defaultValue/placeholder string is invented: the native marked first empty option supplies placeholder text and clear behavior.

Absent native state is value=null for an empty select, selectedIndex=-1, listSize=0, name="", multiple/disabled/required=false, form=null outside forms, and empty native collections. A nonempty single dropdown normally selects its first enabled option unless native defaults say otherwise. Logical size defaults to medium, status to null and borderless to false. checkValidity, reportValidity, setCustomValidity, focus, blur, add, item, namedItem and showPicker delegate to the native owner. remove(index) removes a native option; remove() removes the host. The browser owns picker availability, user-activation exceptions, keyboard/typeahead, constraint validation and invalid focus.

Native input, change and invalid retain their targets, order and flags without m:input/m:change aliases. Programmatic value writes, option changes and reset emit no input/change. clear() is explicit user intent: it emits untrusted input, then change, then noncancelable m:select-clear({previous}) once on a real editable change. Clear selects the marked placeholder or null in single mode, [] in multiple. Disabled/fieldset, hidden/inert and advisory aria-disabled/aria-readonly guard clear. Cancel the optional named type=button click, including at a later bubbling listener, to cancel its deferred action. Native invalid is non-bubbling and cancelable; listen on native or capture it.

The optional labelled external text/search input requires a native list (multiple or native size ≥ 2). Filtering is literal and case-insensitive; selected nonmatches stay visible, author-hidden options remain hidden, and IME drafts are not replaced. refresh() updates helpers after direct native property writes. Disconnect releases observers, listeners, queued clears/reset work and only owned helper visibility/disabled attributes. Reconnect retains native state. Errors surface through error and non-bubbling m:select-error; correct anatomy and refresh to recover. Mode changes use the browser's own selectedness transition, not a custom keyboard engine.

ESM imports core and markup-ui-native-select.js. Classic order is core, native-select, select. The internal native dependency is also used by the existing TreeSelect and Popselect compositions; it registers nothing and exposes no public factory facade. Those compositions are not Select dependencies. No Input/Dropdown/Popover/aggregate constructor or runtime metadata is loaded. Optional m-bind supports string/null/arrays and native input/change; it is not a dependency.

The .m-select native skin and --m-select-* author overrides retain 22/28/34/40px visual minimums, native list height and arrows, visible focus, disabled/status colors, logical RTL layout and light/dark/forced-color/print behavior. Native optgroups retain platform row/group boundaries. There is no custom popup sizing, virtualization or animation. Canonical size/status/borderless replace archived data-* styling.
