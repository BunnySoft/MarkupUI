Behavior and Web mapping

Author m-cascader with typed options data or its JSON attribute. Web rendering owns a labelled fieldset and up to eight dependent native selects. Public markup requires no native list, select, option or active Tree. Additional content is preserved.

value is one terminal key or null. path includes incomplete selections; defaultValue is the independent native form reset target. Programmatic writes are silent. User actions emit one bubbling m:cascader-change; native field events remain native. Native select keyboard interaction replaces the former nonfunctional hover-trigger setting.

Data is bounded to 2,000 nodes and eight levels, with up to 200 nodes per load. Keys are unique; labels are plain text. Load callbacks receive Web node descriptors and an abort signal, and return data with optional synchronous disposal. Invalid or missing defaults block a successful reset until corrected. Native controls are exposed for explicit Web interoperability. Form and Button are used only by these examples, not required by Cascader.
