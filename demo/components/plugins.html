Optional Plugins Retained root plugins are optional Web extensions. They do not replace the selectable DataTable and Rate families. Their bounded behavior below is an implementation baseline, not approval of a portable contract. Data and ownership Assign rows as an array of at most 1,000 plain records, containing strings, finite numbers, booleans or nullish cells. Custom array prototypes, hidden symbols, executable array/record accessors, object cells and unsafe prototype keys are rejected before rendering. Missing cells render empty and text is never interpreted as HTML. In-place edits require refresh(). Direct DataColumn children define up to 32 unique, safe, nonempty keys. The key and label string properties and sortable boolean property update the table. Invalid synchronous writes/refreshes throw; invalid observed column changes emit bubbling, noncancelable m:error with the Error as detail and preserve the last valid table. Correcting the configuration resumes rendering. Sorting uses native buttons and numeric-aware text comparison. Enter, Space or a click toggles ascending/descending order and emits bubbling, noncancelable m:sort with { key, direction }, where direction is asc or desc. Property writes are silent. Removing the sorted column resets sorting. Surviving header buttons retain identity and focus; removing a focused button moves focus to the first remaining sort button. Authored content survives refresh and reconnection. Editing, selection and virtualization are not provided. Rating Review: Set score to 2 Toggle disabled Toggle maximum Reconnect rating No user change. Score selection Rating is a non-form group of native score buttons. Give the group an accessible name with aria-label or aria-labelledby. Tab navigates buttons; Enter, Space or a click selects a score. The selected button exposes aria-pressed, not radio semantics. Use the separate Rate family for native radio groups, form submission and validation. The max property/attribute defaults to 5 and accepts integers from 1 to 10. Value defaults to 0 (unselected), and accepts integers from 0 to max. Set value within the new range before reducing max. Invalid property writes throw before mutation; malformed attributes emit bubbling, noncancelable m:error with the Error as detail and keep the last valid rendering until corrected. No rounding or clamping is performed. Value and attribute writes are silent. A changed user selection emits bubbling, noncancelable m:change with the numeric score as detail. Selecting the same score again is silent. Disabled is a boolean presence attribute/property; owned buttons also respect a containing native disabled fieldset. Disable does not clear the value. No clear action, half scores, readonly mode or form participation is provided. Authored nodes and surviving buttons retain identity during updates. If reducing max removes the focused button, focus moves to the last remaining button.
