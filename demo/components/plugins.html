Optional Plugins Retained root plugins are optional Web extensions. They do not replace the selectable DataTable and Rate families. Their bounded behavior below is an implementation baseline, not approval of a portable contract. Data and ownership Assign rows as an array of at most 1,000 plain records, containing strings, finite numbers, booleans or nullish cells. Objects, executable accessors and unsafe prototype keys are rejected before rendering. Missing cells render empty and text is never interpreted as HTML. In-place edits require refresh(). Direct DataColumn children define up to 32 unique, safe, nonempty keys. The key and label string properties and sortable boolean property update the table. Invalid synchronous writes/refreshes throw; invalid observed column changes emit bubbling, noncancelable m:error with the Error as detail and preserve the last valid table. Correcting the configuration resumes rendering. Sorting uses native buttons and numeric-aware text comparison. Enter, Space or a click toggles ascending/descending order and emits bubbling, noncancelable m:sort with { key, direction }, where direction is asc or desc. Property writes are silent. Removing the sorted column resets sorting. Surviving header buttons retain identity and focus; removing a focused button moves focus to the first remaining sort button. Authored content survives refresh and reconnection. Editing, selection and virtualization are not provided.
