Membership, API and ownership

      
Set property-only options with plain records containing a unique string
        value, readable label and optional disabled.
        Data is copied and validated; updates retain surviving native options and membership.
        Empty data clears the lists. Native option/fieldset authoring is an explicit Web
        interoperability path, not required portable markup.

      
value is ordered target membership, not highlighted selection.
        Writes update both native panes through the same controller without emitting
        m:change. Unknown/duplicate keys and forbidden locked-member changes fail
        before movement. defaultValue defines initial/reset membership;
        later writes do not move members. Reset preserves locked members and reports
        vanished defaults through readonly state.

      
moveToTarget/moveToSource move explicit keys, or matching
        staged options when omitted. Bulk methods use matching unlocked options.
        Programmatic moves retain highlights and outside focus; successful movement
        methods emit one m:change. Uncanceled native user actions emit the same
        public event asynchronously. Highlights emit m:stage without changing membership.

      
name serializes membership, not staging; native selects remain unnamed.
        Configure it before connection or while disconnected. Automatic submission needs
        native formdata support; appendTo provides explicit manual serialization.
        required uses native membership validity. disabled disables
        the fieldset without erasing authored control disables.

      
The element maps properties/data and creates or adopts its native fieldset.
        createTransfer is the explicit native-Web entry to that same controller.
        There is no separate button-list mode. Disconnect releases listeners, form ownership
        and timers; reconnect retains nodes, highlights, membership and defaults.
        state and methods need a connected owner; pending properties may be
        assigned before connection. native is Web-only.
