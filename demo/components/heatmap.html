Data and accessibility

Author m-heatmap with typed data/settings or JSON attributes. The Web renderer owns the native captioned table, seven weekday rows, labelled day buttons, legend and nonlive detail text. No native table or cell template is required. Button and Typography are separate demo selections.

At most 366 date records and a 366-day range are accepted. Dates are Gregorian YYYY-MM-DD values, not timestamps. Duplicate dates, out-of-range data, nonfinite numbers and asynchronous descriptions are rejected before changing the display.

Settings writes merge supplied fields. The numeric domain, four thresholds, locale, weekday start, labels and five-color palette are explicit settings. Equal domains use the midpoint; outside values clamp and remain marked. Loading keeps real displayed data, not invented placeholder values.

Arrow keys navigate dates, Home/End move within a weekday row, and Ctrl+Home/End reach the range boundaries. Enter/Space explores a day. Values and missing markers remain readable without color; focus and surviving day controls remain stable during data updates.
