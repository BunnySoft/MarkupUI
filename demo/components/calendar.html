Behavior and Web mapping

Author m-calendar; the Web renderer exposes a named group and creates one captioned native table, native buttons and plain readouts. Core and Calendar are the only required runtime files. Box, Button and Typography are additional selections for this page, not Calendar dependencies. Existing native Calendar anatomy can be adopted before connection as a Web-only escape hatch; it uses the same validation, ownership and lifecycle, not a second factory.

value is null, a canonical YYYY-MM-DD date, or a YYYY-MM month. Month view selects days; year view selects months. Switching modes preserves the value's original precision. min and max are inclusive dates within years 0001-9999. A month is available when it overlaps the date interval. Day callbacks do not search or annotate month cells. Validation round-trips the existing native UTC Gregorian carrier and rejects normalization; Calendar does not require browser support for input[type=date]. The carrier is not the public value or a timezone conversion policy.

Property writes and configure(settings) are silent and atomic. select emits m:change only when the value changes; panel changes emit m:calendar-panel-change first. Both bubble. The change detail includes value, previousValue, year, month, date and reason; month selections have a null date. Failed user updates retain the previous view and emit m:calendar-error.

panel is independent of selection. todayValue maps to the today attribute and initially uses the local date at construction; an empty attribute or null disables the marker. today() navigates without selecting. defaultValue maps to default-value; reset() restores it. Calendar is not a named form field and native form reset does not reset its selection.

The native day/month buttons use one roving tab stop. Arrow keys move focus, Home/End move within a row, and PageUp/PageDown move the panel; Shift uses years. In year view PageUp/PageDown move by year. Enter/Space retain native button activation. Unavailable dates remain discoverable but cannot be selected. Disabled, native fieldsets, RTL direction, external focus and authored node identity are retained. Month tables scroll within narrow viewports.

isDateDisabled and getDayContent are synchronous Web callbacks. Annotations are literal text of at most 512 characters, never HTML. Refresh rechecks policy without clearing unavailable selections. Native table/template adoption requires a connected document-root scope, an accessible name, noninteractive fallback content, separate plain number/marks/note parts and distinct labelled type=button actions. Disconnect restores adopted fallback nodes, listeners and still-owned attributes.
