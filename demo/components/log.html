No syntax highlighter, terminal escapes, automatic links, network stream, clipboard or virtual-window engine. The large local fixture has 10,000 actual line spans, not one giant text node presented as virtualization.

Tab to the readout and use native arrows/PageDown/End. Select text normally. LF/CRLF/lone CR normalize to LF; a final CR in an append waits for another chunk or Flush. Follow only advances when already near the bottom and no selection is active. Updates that would change selected text are rejected for explicit retry.

Retention and selection are explicit

This demo retains at most 10,000 LF-delimited records and 1,000,000 UTF-16 code units. Each record is at most 16,384 code units. Blank and final empty records count. Appending never inserts a newline for you; the 25-line button deliberately does. Old complete records are removed at capacity. No record is truncated partway. Selection of an affected record blocks the update; deselect before retrying.

All retained records are in the DOM for native selection/find/printing. Line numbers are decorative retained-buffer positions, not stable identities. Print expands and wraps the full retained text. No full-history or clipboard-copy promise is made.
