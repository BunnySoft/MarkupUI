Behavior, accessibility and styling

Defaults: vertical=false, inline=false, reverse=false, wrap=true, size=medium, align=normal, justify=start, rowGap=null and columnGap=null. A column always uses nowrap; returning to a row restores the stored wrap preference. Unlike Space, Flex preserves the native alignment vocabulary (including flex-start, flex-end, self-start, self-end, left/right and baseline variants where applicable) and supplies no item-box class. Native start/end and flex-start/flex-end can differ in reversed layouts.

vertical, inline and reverse are presence booleans: even text "false" enables them. Remove the attribute or set the property to false to disable. wrap accepts empty/true/false and defaults to true when absent. Invalid properties throw before mutation; invalid attributes throw on validation/read rather than silently default. Gap properties accept null or finite nonnegative numbers, including zero/fractions, mapped to CSS pixels on Web. Numeric attributes require JavaScript; the other layout styles work without it.

Native CSS determines layout and responsiveness. The four public tokens --m-flex-row-gap, --m-flex-column-gap, --m-flex-align and --m-flex-justify override preset/keyword CSS. Tokens inherit normally: set them to initial on a nested container to return to its own preset. Explicit typed gaps temporarily own native row-gap/column-gap and do not inherit. Removing a gap or disconnecting restores only still-owned styles, preserving later application edits; reconnect reapplies the typed values.

Colors, borders, relative units, safe/unsafe alignment, align-content, item grow/shrink/basis, intrinsic minima, wrap-reverse and media/container queries remain native Web CSS, not parsed style objects or measurement APIs. Direct elements have min-inline-size:0; authors may restore auto for intrinsic content. Text alignment inherits independently of the layout align attribute, and authored text-align still wins. Overflow is never automatically clipped. Modern flex-gap support is required; no support detector, fallback margin system or older-browser polyfill is supplied.

Flex creates no wrappers, controls, observers, listeners, roles or tab stops. Text, comments, hidden nodes, templates, late children and nested components remain authored nodes. Templates are inert, ordinary hidden nodes occupy no gap, and hidden=until-found is not converted to ordinary hidden. Focus, native keyboard activation, forms and labels retain their owners. Pre-upgrade properties replay before first rendering; reconnect never duplicates content. Visual reverse does not reverse Tab order.

Passive Flex content may appear in Collapse headers, Dropdown labels and Tooltip panels. Those consumers still reject interactive descendants, arbitrary custom widgets and shadow roots; Flex does not loosen their content contracts. Outside those regions, normal interactive content is welcome.

The former .m-flex/data-* CSS adapter is replaced by m-flex and the direct attributes shown here. Existing m-row, m-stack, Grid and Layout aliases are not registered or replaced by this family. No provider, item renderer, separator, source tuple/string parser or framework theme-object API is added.

Outside Flex, native content and styles remain unchanged.
