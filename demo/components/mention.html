Canonical API and behavior

  • value: string reads live native text; "" is empty, not null. Property assignments are silent, reject nonstrings and never reflect a second host value. defaultValue is separate native reset text. The host value attribute maps to it, following native pristine/dirty value rules; removing the attribute sets an empty default.
  • native exposes the actual Web editor for native name, required, validity, selection and form association. Original node identity, author labels, ARIA and listeners survive configuration and reconnect. Native readonly, disabled and disabled-fieldset eligibility govern suggestions.
  • configure(configuration) explicitly replaces the configuration atomically. Static options and an async load are mutually exclusive. setOptions(options) updates static data; switching data sources requires configure. No schema change rebuilds the editor or clears text, defaults, caret or composition state. prefix reads the first configured prefix; assigning it replaces the set with one character. Its attribute declares a single prefix; multiple prefixes use typed configuration.
  • Prefixes are 1–8 unique nonwhitespace BMP characters; separator is one distinct BMP character. Defaults: prefix @, separator space, maxResults 20, minQueryLength 1, maxQueryLength 64 and debounce 120 ms. Maximum results are 1–100, query bounds 0–256 (maximum at least 1), debounce 0–1000 ms. Invalid settings/options fail rather than truncating, coercing or inventing a parser.
  • Static matching is case-sensitive label/value startsWith; a custom filter must return a boolean. Loaders receive the unchanged prefix/query, original UTF-16 caret bounds, native control and AbortSignal. Option labels are plain text, custom classes are supported, and only the validated option value is inserted. IME, Unicode boundaries, maxlength, selection ranges and text after the caret are preserved.
  • Selection emits one bubbling native input with insertReplacementText, then one bubbling noncancelable m:select from that same editor with { value, option, prefix }. No synthetic change event or host redispatch exists. Search/results/error/visibility/reject notifications also bubble from the native editor. Programmatic writes and reset do not emit fake input/selection events.
  • query() returns an updated/skipped/aborted result and rejects unexpected loader errors; context, error and connected expose owner state. close(), refresh(), editing, reset and configuration invalidate pending and queued selection work. The named adjacent panel uses ordinary native buttons, not a fake combobox, caret mirror or popup geometry engine. No-JS native editing/forms remain available; screen-reader and real-device acceptance are not claimed.

Minimum runtime is shared core plus Mention and its CSS; Button, Box and Typography are extra demo selections. Portable <m-mention> creates a textarea and panel when no editor is authored. Raw editor, label, form and panel markup above is the explicit Web adoption surface. Author at most one text/search input or textarea and one hidden named panel with an empty [data-mention-options] list and optional nonlive [data-mention-status]. Invalid anatomy fails visibly instead of silently disabling enhancement.
