100,000 items

100,000 data items, 32px rows, 320px viewport, three rows of overscan per edge. This is a list, not an interactive grid or a form serialization engine.

    Mounted controls only

    Native input, select and textarea drafts are saved to caller data on input/change. Only mounted controls submit; scrolling is not FormData serialization. A focused row is pinned until focus leaves. Fixed 48px rows cannot expand for text.
