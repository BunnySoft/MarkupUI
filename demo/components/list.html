    API

    Generated from TypeScript accessors and documentation comments at build time, separately from the runtime. Native HTMLElement properties and methods remain available.

    Behavior and accessibility

    Properties and validation

    bordered defaults to true; setting bordered="false" removes the border. size accepts small, medium, or large. clickable and hoverable are presence attributes. showDivider defaults to true and can be disabled with show-divider="false".

    Accessibility and layout

    Lists with direct m-list-item children maintain role="list" on the container and role="listitem" on items. When an explicit items container such as a ul or ol is authored, header and footer stay outside the semantic list. Native ordering, start, and value attributes on ordered lists are fully preserved.
