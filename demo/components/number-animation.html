Behavior

play() always starts a new run from from, even while playing or paused. pause() freezes a running animation and does nothing while idle or already paused. resume() continues only a paused run, preserving its elapsed animation time and excluding the pause gap. reset() cancels the run and displays from without completion.

Connecting or reconnecting starts from the beginning; disconnecting cancels pending frames and discards paused progress. Changes to from, to, duration or precision replay the animation. Zero duration or a reduced-motion preference displays to immediately. Successful completion emits m:finish once with { value: to }; pause, reset and disconnect do not.
