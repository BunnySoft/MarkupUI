# Styling

Styling is part of each element's contract, not a copy of a framework's CSS.
The current design separates semantic element choices from unrestricted presentation values.

## Reading order

1. [Presentation and resources](01-design.md): ownership, tokens, DOM boundaries and delivery.
2. [Visual review](02-review.md): how to establish and record acceptance for rewritten elements.

An element's finite choices, such as shape, size and semantic tone, select presentation.
Exact colors, arbitrary radii, spacing, shadows and typography belong to theme/style resources.
The [Element Contracts](../elements/README.md) define the choices available to each element.

Visual comparisons are useful evidence, but a previous audit does not validate a rewritten
implementation. No historical completion totals are carried into current acceptance.
