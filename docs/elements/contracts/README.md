# Element Contracts

Use the [ordered catalog](../02-catalog.md) to choose a contract.
Each page follows the [shared model](../01-contract.md) and inherits its rules.

Review each page's status and **Decisions** section before implementation.
Documentation is generated separately from the runtime; contract presence alone
does not mean another component's rewrite is complete.

## Required before release

- [Chart](chart.md): ECharts-shaped `m-chart`, first-batch chart types, all five data-source
  forms and release acceptance. Required scope is selected; detailed API decisions and
  implementation remain pending.
