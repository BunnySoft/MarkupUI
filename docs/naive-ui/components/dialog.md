## Retained architecture and evidence

- [Canonical loading/API/ownership/acceptance](../../components/dialog.md)
- [Implementation](../../../src/components/dialog/) · [tests](../../../tests/dialog.test.ts)
- [Local demo](../../../demo/components/dialog.html), separate HTML/CSS/JS
- Native authored content, optional lifetime and optional decisions are separate.
- CSS-only presentation never claims modal state. Native showModal/show/close/cancel,
  returnValue and authored method=dialog validation remain native.
- False/void/Promise callbacks retain their decision meaning; errors are surfaced and
  stale results cannot close a replacement opening. Provider/reactivity are not copied.

The live [official route](https://www.naiveui.com/en-US/os-theme/components/dialog) returned
HTTP 404 to the fetch client; pinned Markdown remains the API authority. Source review
inspected [Dialog.tsx](https://github.com/tusen-ai/naive-ui/blob/42a52e6436b38bed456fee19eb0b89cdcd00fcc2/src/dialog/src/Dialog.tsx), [dialogProps.ts](https://github.com/tusen-ai/naive-ui/blob/42a52e6436b38bed456fee19eb0b89cdcd00fcc2/src/dialog/src/dialogProps.ts),
[DialogEnvironment.tsx](https://github.com/tusen-ai/naive-ui/blob/42a52e6436b38bed456fee19eb0b89cdcd00fcc2/src/dialog/src/DialogEnvironment.tsx), [DialogProvider.ts](https://github.com/tusen-ai/naive-ui/blob/42a52e6436b38bed456fee19eb0b89cdcd00fcc2/src/dialog/src/DialogProvider.ts) and
[shared theme declarations](https://github.com/tusen-ai/naive-ui/blob/42a52e6436b38bed456fee19eb0b89cdcd00fcc2/src/_mixins/use-theme.ts). NDialog only notifies action handlers;
Environment owns false/Promise dismissal and Provider supplies the reactive collection.
The Markdown type/default table differs from the source: source defaults to default and
also supports info; both claims are recorded, not silently conflated.

4. [x] **Test nested dialogs.** Native forms, focus, nesting, fallback, long-content and packaging gates accepted.

### Native primitives and fallback

Use authored named native dialog and unmarked method=dialog forms, or CSS-only section
content without enhancement. The optional controller detects exact native methods and
returns modal/modeless/inline mode honestly. No modal polyfill, fake aria-modal, global
focus/scroll manager, portals or commandfor double handling. Text options are text only.
Author dispose before intentional DOM removal; ancestor-removal observation also releases
owners. See the canonical contract for all narrowed property semantics and omitted APIs.
