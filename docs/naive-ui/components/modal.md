# Modal

**Plan: 🟢 Verified retained generic native scope.** This is native modality and authored
content, not a framework provider, render/preset engine or confirmation service.

## Retained architecture and evidence

- [Canonical loading/API/ownership/acceptance](../../components/modal.md)
- [Optional implementation](../../../src/components/modal/) · [tests](../../../tests/modal.test.ts)
- [Local demo](../../../demo/components/modal.html), separate HTML/CSS/JS
- Reuses the accepted [native lifetime](../../../src/components/dialog/native.ts) and
  composed native CSS, not Dialog's decision footer. Legacy aggregate/shared sources remain unchanged.
- showModal requires real native modality; show is an explicit modeless/inline choice.
- No body-scroll lock, custom focus trap, whole-document inert/aria-hidden manager or portal.

Source review inspected [Modal](https://github.com/tusen-ai/naive-ui/blob/42a52e6436b38bed456fee19eb0b89cdcd00fcc2/src/modal/src/Modal.tsx), [BodyWrapper](https://github.com/tusen-ai/naive-ui/blob/42a52e6436b38bed456fee19eb0b89cdcd00fcc2/src/modal/src/BodyWrapper.tsx), [presetProps](https://github.com/tusen-ai/naive-ui/blob/42a52e6436b38bed456fee19eb0b89cdcd00fcc2/src/modal/src/presetProps.ts),
[Provider](https://github.com/tusen-ai/naive-ui/blob/42a52e6436b38bed456fee19eb0b89cdcd00fcc2/src/modal/src/ModalProvider.ts), [Environment](https://github.com/tusen-ai/naive-ui/blob/42a52e6436b38bed456fee19eb0b89cdcd00fcc2/src/modal/src/ModalEnvironment.tsx), exports and the draggable interface.
The live official route returned HTTP 404 to the fetch client; pinned Markdown is authoritative.
Source showMask=false disables focus trapping and mask interaction; a transparent native
backdrop is not that behavior. Source preset callbacks can return false/Promise; generic
Modal intentionally omits that lane instead of claiming synchronous native events preserve it.
Source displayDirective/teleport/transitions/reactivity and private/deprecated APIs are not copied.

## Migration steps

**Delivery phase:** P3 — modal foundations. **Task state:** 🟢 Verified retained scope.
**Prerequisites:** accepted Dialog native lifetime and native authored controls.
**Next task:** Drawer, using the same actual native ownership foundations.

1. [x] **Specify top-layer state.** Native modes, naming/focus, Escape/cancel/returnValue and fallback accepted.
2. [x] **Map preset composition.** Authored generic/Card-intent/Dialog-CSS regions; explicit incompatible omissions.
3. [x] **Separate optional services.** Trusted-template owner/instances replace provider/render/reactive APIs.
4. [x] **Verify overlapping lifetimes.** Reopen/native forms/nesting/focus/disposal, local opening order, CSS and packaging accepted.

### Native primitives and fallback

Real named native dialog, authored heading/forms and optional native templates retain the
browser top layer. Missing showModal does not silently become a modal-looking modeless UI;
use explicit show or a visible inline/native-link path. Native form validation is untouched.
Dispose before intentional DOM removal; ancestor observation also releases ownership.
