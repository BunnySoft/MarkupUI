## Retained architecture and evidence

- [Canonical loading/API/ownership/acceptance](../../components/drawer.md)
- [Optional helper/CSS](../../../src/components/drawer/) · [tests](../../../tests/drawer.test.ts)

  no Modal presentation, Dialog decision footer, provider or global focus/scroll manager.
- Native physical edge docking, CSS extents, authored heading/body/footer/close/form
  regions and body scrolling retain the useful side-panel/content scope.

The live official route returned HTTP 404 to the fetch client; pinned Markdown remains
authoritative. Source resizes through mouse/body listeners and uses Vue focus/scroll/
teleport/transition coordination. These systems are not transplanted. DrawerContent's
close is immediate; it is not Dialog's false/Promise decision contract.

**Next task:** Message, then Notification; Collapse Transition/Discrete remain separate.

2. [x] **Resolve lifecycle.** Strict modes, native cancel/focus/returnValue and current-opening-order ownership accepted.
3. [x] **Scope resizing explicitly.** Pointer-edge resizing/bounds/callbacks omitted; useful external CSS sizing retained.
4. [x] **Test panel edges.** Physical/logical edges, RTL/zoom/scroll/forms/nesting/removal/fallback and packaging verified.

### Native primitives and fallback

Real native dialog owns modality. showModal does not silently degrade; explicitly choose
modeless/inline show or ordinary aside/navigation/link content. DrawerContent is authored
HTML/CSS, not a new tag/provider. No inferred heading level, false aria-modal, document
scroll lock, transition completion signal or fabricated resize callback. See the canonical
contract for form association/default submitter guidance and exact ownership requirements.
